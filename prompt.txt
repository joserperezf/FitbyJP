REQUERIMIENTOS FUNCIONALES POR UNIDAD OBLIGATORIO:

-Intro + Navegación Estructura base con tabs, routing, lazy loading, mínimo 4 páginas.
-Interfaces y gestos Componentes Ionic (cards, lists, inputs) + gestos (swipe, pull-torefresh).
-Conectividad Detección de estado de red (online/offline) o WiFi.
-Bluetooth/NFC Integración BLE para escaneo de dispositivos O NFC para compartir datos.
-Geolocalización GPS + mapa interactivo con marcadores Leaflet.
-Multimedia Reproductor de audio O video con controles personalizados.
-Cámara Captura de foto O escaneo de código QR con @capacitor/camera.
-Almacenamiento CRUD con SQLite, IndexedDB o @ionic/storage.
-Servicios Web Consumo de API REST (GET, POST) con HttpClient o fetch.

Recursos de Apoyo:

-Ionic Documentation ionicframework.com/docs Componentes, plugins, CLI de Ionic.
-Angular Documentation angular.dev Componentes, servicios, routing, forms.
-Capacitor Documentation capacitorjs.com/docs Plugins nativos: cámara, GPS, BLE, NFC.
-Leaflet.js leafletjs.com Mapas interactivos gratuitos.
