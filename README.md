# Fit by JP

Fit by JP es una aplicación móvil multiplataforma diseñada para organizar entrenamientos físicos, visualizar métricas de progreso, realizar monitoreo de rutinas en tiempo real y consumir contenido de motivación deportiva en una sola interfaz limpia y moderna.

### Tecnologías Utilizadas
- Ionic Framework 8
- Angular 18
- Capacitor 6
- TypeScript y HTML5
- SQLite y Local Storage
- Plugins Nativos: Cámara, Bluetooth LE, Geolocalización, Red

### Instrucciones de Instalación
Para ejecutar este proyecto localmente en modo desarrollo:

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/joserperezf/FitbyJP.git
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Ejecutar en el navegador:
   ```bash
   ionic serve
   ```

### Versión de Escritorio
En este repositorio se incluye una carpeta llamada `VersionEscritorio` con la aplicación compilada. Para ejecutarla sin depender del entorno de desarrollo, simplemente ejecuta el archivo `EjecutarApp.bat` en esa carpeta.
